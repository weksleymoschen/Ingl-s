# Color Adventure — Aventura das Cores

Jogo da memória de cores em inglês, com a marca WM Jogos Educativos.

## Jogar

Informe o nome do aluno, escolha 6 ou 10 cores e clique em Começar. Forme pares entre a cor e sua palavra em inglês. O resultado mostra os pares, as tentativas e o tempo. A música instrumental começa depois do clique e pode ser desligada.

## Publicar no GitHub Pages

1. Crie um repositório chamado `color-adventure`.
2. Extraia o ZIP e envie os arquivos que estão dentro dele para a raiz do repositório. O `index.html` deve aparecer diretamente na raiz.
3. Abra Settings → Pages.
4. Em Source, escolha Deploy from a branch.
5. Selecione a branch main e a pasta / (root). Clique em Save.
6. Aguarde a publicação e abra o endereço exibido no GitHub Pages.

## Atualizar

Substitua o index.html neste mesmo repositório e confirme a alteração. O GitHub Pages atualizará o jogo.

## Testar no computador

Abra index.html no Chrome. Não precisa instalar dependências ou fazer login. Fundo, marca e ilustrações estão incorporados; a música usa Web Audio.
